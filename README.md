## 💡 How It Works

### Smart Scheduling
Set shutdown times with precision:
- **Specific times** (e.g., 11:00 PM daily)
- **Countdown timers** (e.g., shutdown in 2 hours)
- **Recurring schedules** (weekdays, weekends, custom days)

### Intelligent Triggers
Automatic shutdown based on:
- 🔋 **Battery Level** - Hibernate when battery drops below threshold
- 💻 **CPU Activity** - Delay if CPU usage is high (rendering, downloads, etc.)
- 🌐 **Network Activity** - Wait for active transfers to complete
- ⏱️ **Idle Detection** - Shutdown after specified inactivity period

### Gamification
Make shutting down fun:
- ⭐ **Earn Points** - +10 points per successful shutdown
- 🔥 **Maintain Streaks** - Consecutive shutdown days
- 🏆 **Unlock Achievements** - 9 achievements to collect
- 🎨 **Unlock Themes** - Gold theme (100 points), Cyberpunk theme (7-day streak)
