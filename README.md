# Supreme Lite Auto Shutdown ⚡

A lightweight, smart, and gamified shutdown scheduler for Windows 10/11.  
Built by an indie developer to make PC power management simple, safe, and fun.

---

## ✨ Features
- 🔌 Schedule shutdown, restart, sleep, hibernate, lock, or log off
- 🕒 Idle detection with customizable timeout
- 🔋 Battery triggers (shutdown/hibernate on low battery)
- 📡 CPU/Network awareness (delays shutdown if busy)
- 🎮 Gamification: points, streaks, achievements, unlockable themes
- 🎨 Multiple themes (Dark, Light, Blue, Red, Gold, Cyberpunk)
- 💾 Portable EXE — no installation required
- 🔧 Installer (MSI) — integrates with Windows Start Menu
